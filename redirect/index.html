Nothing happened? bussola may not be installed, or bussola:// links may not be registered on this computer.

  • Open it on GitHub
  • Install bussola, then run bussola install-handler once (more on bussola:// links).

This page opens links in bussola, where bussola:// links are not clickable. Put https://bussola.spoki.com/ in place of https:// in a GitHub pull request link, or in place of bussola:// in a bussola link:

https://bussola.spoki.com/github.com/<owner>/<name>/pull/<number>

Nothing is sent to a server: the page only rewrites the address in your browser.
